# Isaac Demo

> 基于 Unity 的 2D 俯视角射击 Demo，玩法致敬《以撒的结合》（The Binding of Isaac）。

## 项目简介

使用 Unity 2D 制作的俯视角射击 Roguelike 原型：玩家在瓦片地图中移动、向四 / 八方向射击击杀敌人；敌人会追击玩家并造成伤害；角色拥有血量、无敌帧、受伤 / 死亡动画。前几秒摄像机跟随、移动手感、碰撞、击退、动画切换等问题均在开发过程中逐一定位并修复。

## 技术栈

- **引擎**：Unity 2022（2D 模板）
- **语言**：C#
- **核心系统**：Unity 2D Physics、Tilemap、Animator 状态机、Rigidbody2D

## 玩法与操作

| 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 角色移动 |
| `↑` `↓` `←` `→` | 朝对应方向射击（按下一次持续发射，可随时改向） |
| `Ctrl` | 停止射击 |
| Inspector `eightWay` | 勾选后切换为八向射击（含对角线） |

- 敌人接触玩家造成伤害，角色拥有**无敌帧**（受击后短暂免伤 + 闪烁反馈）。
- 角色血量归零触发**死亡动画**，同时全场敌人停止行动。

## 已实现功能

- 帧率无关平滑的摄像机跟随
- 基于物理的角色移动（Rigidbody2D + 插值）
- 敌人 AI 追击与停止距离控制
- 触发器（Trigger）伤害检测，玩家受伤区与敌人解耦
- 双向击退系统（受击双方互相弹开）
- 瓦片地图边界碰撞，防止穿墙
- 子弹发射系统（方向、八向、超时销毁、命中检测）
- 受伤 / 死亡动画状态机，整体精灵与头 / 身分离渲染
- 背景音乐（AudioSource + 循环）

## 关键技术点（面试可展开）

1. **帧率无关的摄像机平滑**：将插值系数改为 `t = 1 - Mathf.Pow(1 - k, dt * 60)`，避免高 / 低帧率下跟随速度不一致，并消除因稳态滞后导致的“跟随几秒后出画”问题。
2. **Rigidbody2D 插值消除抖动**：开启 `Interpolation`，解决物理按固定步长更新、渲染按帧率更新带来的硬跳变。
3. **触发器伤害解耦**：受伤检测（Trigger）挂在玩家身上，敌人只负责上报伤害值（`EnemyDamage`）。新增敌人种类只需挂组件、填数值，**零改动玩家代码**。
4. **击退与移动的速度覆盖冲突**：移动脚本每帧用 `rb.velocity` 绝对赋值，单次 `AddForce` 会被下一帧覆盖。使用 `[DefaultExecutionOrder(1000)]` 让 `Knockback` 在移动脚本之后执行并覆盖速度，实现稳定击退。
5. **子物体碰撞体的层级查找**：玩家碰撞体分布在头 / 身子等子物体上，使用 `GetComponentInParent<T>()` 向上查找，保证事件与组件正确关联。
6. **整体精灵 vs 头 / 身分离的动画切换**：受伤 / 死亡时隐藏头身子精灵、显示整体精灵播放动画，避免多层精灵叠加；死亡时停用玩家移动 / 攻击组件并清零速度，同时通过检测 `PlayerHealth.IsDead` 让敌人停止追击。
7. **朝向翻转隔离**：仅对“身体”子物体做 `localScale.x` 镜像，不镜像根物体，避免攻击动画被整体翻转导致左右反向。

## 项目结构（节选）

```
Assets/
├── Scripts/
│   ├── CameraMove.cs          # 摄像机跟随
│   ├── Bullet.cs               # 子弹
│   ├── Knockback.cs            # 击退（[DefaultExecutionOrder]）
│   ├── Player/
│   │   ├── PlayerMove.cs       # 移动 + 朝向翻转
│   │   ├── PlayerAttack.cs     # 射击逻辑
│   │   ├── PlayerHealth.cs     # 血量 / 无敌帧 / 死亡
│   │   └── PlayerHurtbox.cs    # 触发器受伤检测
│   └── Enemy/
│       ├── EnemyMove.cs        # 追击 AI
│       ├── EnemyDamage.cs      # 上报伤害值
│       └── EnemyHealth.cs      # 敌人血量
├── Animation/                 # Animator 控制器与动画 clip
└── ...                        # 场景、瓦片、精灵资源
```

## 运行方式

1. 使用 Unity 2022（2D 模板）打开本项目。
2. 打开主场景，点击 `Play` 即可游玩。
3. 克隆后首次打开会重新生成 `Library/`（正常现象，已通过 `.gitignore` 排除）。
